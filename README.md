# Практическое занятие №3 — Динамические структуры данных (C# / Avalonia UI)

Оконное кроссплатформенное приложение на **C# (.NET 10 / Avalonia UI)**, реализующее все 4 части практической работы №3 по курсу алгоритмов и динамических структур данных.

---

## Состав проекта по частям задания

### Часть 1. Стек и Обратная польская запись (ОПЗ / RPN)
* **Собственный стек на связном списке (`CustomStack<T>`)**:
  * Реализован на базе узлов `StackNode<T>` без использования встроенных коллекций.
  * Поддерживаемые операции:
    * `1,elem` — `Push(elem)` (добавление элемента на вершину стека за $O(1)$);
    * `2` — `Pop()` (удаление и возврат верхнего элемента за $O(1)$);
    * `3` — `Top()` (просмотр вершины стека за $O(1)$);
    * `4` — `IsEmpty()` (проверка на пустоту за $O(1)$);
    * `5` — `Print()` (вывод всех элементов от вершины к основанию за $O(N)$).
  * Считывание команд из файла [`input.txt`](input.txt) (контрольный пример: `3 4 1,56 1,7 1,cat 2 5 4`) и автоматический бенчмарк для наборов разного размера и состава операций.
* **Вычисление постфиксной записи и перевод Инфикс $\to$ Постфикс (`RpnCalculator`)**:
  * Перевод выражений из инфиксной формы (например, `(7 + 8) / (3 + 2)`) в постфиксную (`7 8 + 3 2 + /`) по алгоритму сортировочной станции Дейкстры.
  * Вычисление постфиксного выражения из файла [`rpn_input.txt`](rpn_input.txt) с поддержкой операций `+`, `-`, `*`, `:`, `/`, `^` и функций `ln`, `cos`, `sin`, `sqrt`.
  * Пошаговая визуализация состояния стека («стаканы» элементов) и автоматический расчёт временной $T(N) = O(N)$ и пространственной $M(N) = O(N)$ сложности алгоритма.

---

### Часть 2. Очередь (FIFO): Своя на связном списке vs Стандартная `Queue<T>`
* **Собственная очередь (`CustomQueue<T>`)** на базе односвязного списка с указателями `_head` и `_tail` и сравнение со стандартным классом `System.Collections.Generic.Queue<T>`.
* Поддерживаемые операции из [`input.txt`](input.txt): `1,elem` (вставка), `2` (удаление), `3` (просмотр начала очереди), `4` (проверка на пустоту), `5` (печать).
* **Сравнительные замеры времени (`QueueCommandProcessor`)**:
  1. Наборы **различной длины** (`100`, `1 000`, `10 000`, `50 000` операций).
  2. Наборы **одинаковой длины (`20 000` операций), но различного состава**, включая сценарий достижения **максимального расхождения по времени** (массовая вставка + периодическая печать, демонстрирующая преимущество непрерывного кольцевого буфера `Queue<T>` по `cache locality` над аллокациями узлов связного списка в куче).

### Часть 3. Практическое применение динамических структур данных
Реализованы 4 интерактивных модуля (с выделением 2 основных проектов):
1. ★ **Список (Двусвязный список) — Плейлист с навигацией (`DoublyLinkedPlaylist`)**:
   * Переходы «Назад» (`Prev`), «Далее» (`Next`), «Перемешать» (`Shuffle`), добавление и удаление текущего трека за $O(1)$ с визуализацией двусторонних ссылок `Prev <-> Next`.
2. ★ **Стек (LIFO) — История браузера (`BrowserHistoryEngine`)**:
   * Два стека `BackStack` и `ForwardStack` на базе `CustomStack<string>`, переходы по URL, кнопки «Назад» и «Вперёд».
3. **Очередь (FIFO) — Спулер печати с приоритетами (`PrintSpoolerEngine`)**:
   * Очередь заданий на принтер с тремя уровнями приоритета, печатью первого задания и отменой любого задания по `ID`.
4. **Деревья — Префиксное дерево (`TrieAutocompleteEngine`)**:
   * Автодополнение поиска по словарю в реальном времени с выводом всех слов по введённому префиксу и добавлением новых слов.

---

### Часть 4. Алгоритмы работы со своим односвязным списком (`CustomLinkedList`) + Бинарное дерево
Реализованы все **12 функций** работы со ссылками собственного односвязного списка целых чисел `L`:
1. `Reverse()` — переворот списка `L` изменением ссылок `Next` в обратном порядке.
2. `MoveLastToFirst()` / `MoveFirstToLast()` — перенос последнего элемента в начало (и первого в конец).
3. `CountDistinct()` — определение количества различных элементов списка.
4. `RemoveDuplicatesKeepFirst()` / `RemoveAllNonUniqueStrict()` — удаление неуникальных элементов из списка `L`.
5. `InsertSelfAfterFirstX(int x)` — вставка списка самого в себя вслед за первым вхождением числа `x`.
6. `InsertOrdered(int e)` — вставка элемента `E` в упорядоченный по неубыванию список `L` с сохранением упорядоченности.
7. `RemoveAll(int e)` — удаление из списка `L` всех элементов `E`.
8. `InsertBeforeFirst(int e, int f)` — вставка нового элемента `F` перед первым вхождением элемента `E`.
9. `AppendList(CustomLinkedList listE)` — дописывание к списку `L` списка `E` (считывание обоих списков из файла [`lists_input.txt`](lists_input.txt)).
10. `SplitByFirst(int x)` — разбиение списка на два по первому вхождению заданного числа `x`.
11. `DuplicateSelf()` — удвоение списка (приписывание в конец списка самого себя).
12. `SwapElements(int val1, int val2)` — обмен местами двух заданных пользователем элементов путём перестановки ссылок узлов.

* **Дополнительно (задание 2024 г. со скриншота — `SerializedBinaryTree`)**:
  * Построение бинарного дерева из строки `ABD*G***CE**FH**J**` (где `*` обозначает `NULL`), визуализация связей `Left` / `Right` и вывод прямого (`Pre-order`), центрированного (`In-order`) и обратного (`Post-order`) обходов.

## Структура репозитория

```text
├── Models/
│   ├── CustomStack.cs        # Часть 1: Свой стек на связном списке + бенчмарки input.txt
│   ├── RpnCalculator.cs      # Часть 1: Перевод Инфикс -> Постфикс, вычисление ОПЗ и оценка сложности
│   ├── CustomQueue.cs        # Часть 2: Своя очередь vs Queue<T> + сравнительные бенчмарки
│   ├── Part3Examples.cs      # Часть 3: Плейлист, История браузера, Спулер печати, Trie, Дерево 2024
│   └── CustomLinkedList.cs   # Часть 4: Свой односвязный список и 12 функций работы со ссылками
├── MainWindow.axaml          # Разметка графического интерфейса Avalonia UI (4 вкладки)
├── MainWindow.axaml.cs       # Логика взаимодействия и визуализации структур данных
├── input.txt                 # Входной файл команд для Стека и Очереди (Части 1 и 2)
├── rpn_input.txt             # Входной файл постфиксного выражения (Часть 1)
├── lists_input.txt           # Входной файл двух списков L и E (Часть 4, п. 9)
└── third.sln                 # Файл решения для Visual Studio / JetBrains Rider
```
